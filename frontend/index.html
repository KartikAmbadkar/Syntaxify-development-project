Understand any code, one line at a time.

Syntaxify turns code you didn't write, or can't quite follow, into plain English. Paste a snippet, pick your language, and see what each line does and why it's there.

Works with Python, Java, C++, JavaScript and more. No signup needed.

Get started
fibonacci.py
def fibonacci(n):
a, b = 0, 1
for _ in range(n):
a, b = b, a + b
return a

Line 4

Moves the pair forward. a takes the value of b, and b becomes the sum of the old a and b.

About

Built to make unfamiliar code feel familiar.

Syntaxify is a code explainer for students, self-taught developers and anyone who has opened a file and wondered what it was doing. Paste a snippet and get a plain-English walkthrough instead of a wall of documentation.

It follows how people actually learn: start with the big picture, drop down to individual lines, and keep asking until it makes sense.
